# Module 2: Пакет супровідної документації (Task 1) (+fix)

## Опис проєкту
Цей застосунок є інтелектуальною системою рекомендацій, розробленою для автоматизації підбору товарів користувачам на основі їхньої історії покупок. У цій фазі проєкту (Module 2) систему доповнено повним пакетом супровідної технічної та презентаційної документації відповідно до чинних стандартів.

## Використані технології
* **Мова:** Python 3.12 (або новіша стабільна версія)
* **Алгоритм:** KNN (K-Nearest Neighbors) для колаборативної фільтрації (метрика `cosine`).
* **Інтерфейс:** `customtkinter` (сучасне графічне вікно в темній темі).
* **Аналітика:** `matplotlib` (візуалізація розподілу популярності товарів).
* **Дані:** `pandas` (маніпуляції з таблицями та побудова розріджених матриць).
* **Логування:** Стандартна бібліотека `logging`.

## Реалізований функціонал
1. **Інтелектуальне ядро:** Система порівнює вектори покупок користувачів за допомогою косинусної схожості та пропонує товари, які купили "схожі" на них клієнти.
2. **Графічний інтерфейс:** Інтуїтивно зрозуміле вікно з полями для введення ID та миттєвого виведення результатів.
3. **Обробка помилок та валідація:** Користувач не може "зламати" програму некоректними даними (текст замість ID, відсутні ID); всі помилки фіксуються у `logs/app.log`.
4. **Конфігурація:** Назви та параметри (версія, шляхи до файлів) винесені у зовнішній `config.json`.
5. **Аналітика:** Можливість переглянути інтерактивний графік популярності товарів одним натисканням кнопки.
