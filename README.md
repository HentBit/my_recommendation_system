# Module 1: Система рекомендацій товарів (Task 1)

## Опис проекту
Цей застосунок є інтелектуальною системою рекомендацій, розробленою для автоматизації підбору товарів користувачам на основі їхньої історії покупок. 

## Використані технології
- **Мова:** Python 3.14
- **Алгоритм:** KNN (K-Nearest Neighbors) для колаборативної фільтрації.
- **Інтерфейс:** `customtkinter` (графічне вікно).
- **Аналітика:** `matplotlib` (візуалізація популярності товарів).
- **Дані:** `pandas` (маніпуляції з таблицями).
- **Логування:** Стандартна бібліотека `logging`.

## Реалізований функціонал
1. **Інтелектуальне ядро:** Система порівнює вектори покупок користувачів за допомогою косинусної схожості та пропонує товари, які купили "схожі" на них клієнти.
2. **Графічний інтерфейс:** Інтуїтивно зрозуміле вікно з полями для вводу та виводу результатів.
3. **Обробка помилок та валідація:** Користувач не може "зламати" програму некоректними даними; всі помилки фіксуються у `logs/app.log`.
4. **Конфігурація:** Назви та параметри винесені у `config.json`.
5. **Аналітика:** Можливість переглянути графік популярності товарів одним натисканням кнопки.
